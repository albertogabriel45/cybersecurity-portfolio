# Pentest - RecruitX

Relatório de Pentest realizado em um ambiente controlado da plataforma **TryHackMe**, simulando uma aplicação web de recrutamento chamada **RecruitX**.

> **Aviso:** Este projeto possui finalidade exclusivamente educacional. Todos os testes foram executados em um laboratório autorizado da plataforma TryHackMe.

---

## Objetivo

Realizar uma avaliação de segurança na aplicação web RecruitX, identificando vulnerabilidades, explorando-as de forma controlada e documentando todo o processo em um relatório técnico de Pentest.

---

## Escopo

- Aplicação Web RecruitX
- Servidor Web
- Avaliação Black Box

---

## Vulnerabilidades Encontradas

- Insecure Direct Object Reference (IDOR)
- Exposição de Token de Redefinição de Senha
- Upload Arbitrário de Arquivos (Remote Code Execution)

---

## Conteúdo do Relatório

O relatório aborda:

- Resumo Executivo
- Escopo do teste
- Metodologia utilizada
- Linha do tempo do ataque
- Descrição detalhada das vulnerabilidades
- Evidências técnicas
- Impacto das vulnerabilidades
- Recomendações de mitigação
- Conclusão

---
